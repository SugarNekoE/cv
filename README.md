# Asai Neko CV

A bilingual, fully static résumé website built with bare Svelte, Vite, mdsvex,
Tailwind CSS, self-hosted Noto Sans fonts, and Lucide icons.

## Content

- `src/contents/CV_zh.md` is the authoritative Chinese résumé and renders at `/`.
- `src/contents/CV_en.md` is the authoritative English résumé and renders at `/en/`.

The Chinese and English entries import these files directly through mdsvex. Edit
the Markdown sources under `src/contents` rather than duplicating résumé copy in
Svelte components.

English text uses Noto Sans. Simplified Chinese uses Noto Sans SC, the web-font
distribution name for the Simplified Chinese Noto Sans CJK variant. Both variable
fonts are bundled locally, including in printed output; the site does not depend
on a third-party font CDN.

The toolbar avatar is served from `public/avatar.png` as a regular static asset.

The favicon is Google Noto Emoji's U+1F431 cat face from the pinned
[`v2.051` artwork](https://github.com/googlefonts/noto-emoji/blob/v2.051/svg/emoji_u1f431.svg).
The unchanged SVG image and its Apache-2.0 notice are stored as
`public/favicon.svg` and `public/noto-emoji-LICENSE.txt`.

## Development

```sh
corepack pnpm install
corepack pnpm dev
```

Validate and build the static site with:

```sh
corepack pnpm check
corepack pnpm build
```

The production output is written to `build/`.

The build uses Vite's native multi-page output for `index.html` and
`en/index.html`, then uses Svelte's server renderer at build time to place the
complete résumé and page metadata into each file. Browser JavaScript hydrates
theme, language, and print controls; no server renderer is deployed.

### Typst printing

The print button loads a browser-side Typst compiler on demand, renders the
current language as vector pages, and opens the browser print dialog. The print
preview can be printed or saved as a PDF by the browser. No PDF is generated by
`pnpm build` or stored in `build/`.

The wasm compiler is a lazy-loaded chunk; only its small entry module is emitted
with the initial page. Noto Sans and Noto Sans CJK SC are subset to the glyphs
used by the current resume plus Typst's generated punctuation and list markers.
The static cross-origin isolation headers in `public/_headers` enable the worker
backend on Cloudflare Pages; Vite's dev and preview servers set the same headers.
Browsers with JSPI can use the fallback backend without isolation.

If a browser cannot invoke printing from the generated print frame, the button
falls back to downloading the browser-rendered PDF. The current site stylesheet
does not define a print layout.

After editing résumé text, regenerate the tracked browser font subsets with:

```sh
corepack pnpm build:typst-fonts
```

This command needs the checked-in devenv environment because it uses `pyftsubset`
and the pinned Noto source fonts.

### Standalone Typst export

An optional native PDF export remains available:

```sh
corepack pnpm build:typst
```

Run this inside the devenv shell. It writes `dist/typst/CV_en.typ`,
`dist/typst/CV_en.pdf`, `dist/typst/CV_zh.typ`, and `dist/typst/CV_zh.pdf`.
These files are outside `build/` and are not deployed by the static site build.
The Typst inputs are generated from the Markdown sources and must not be edited
directly.

## Cloudflare Pages

Connect the repository to Cloudflare Pages and use:

- Framework preset: None
- Build command: `pnpm build`
- Build output directory: `build`
- Root directory: repository root

The generated site does not require Pages Functions, Workers bindings,
environment variables, a client router, or a server runtime. Keep
`public/_headers` in the deployment: it sets the cross-origin isolation headers
needed by the browser Typst worker backend.

Both language pages use the same cat-face favicon; the toolbar avatar remains a
separate image and is not used as browser icon metadata.
